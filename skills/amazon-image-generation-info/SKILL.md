# 亚马逊图片生成信息

根据用户提供的参考图、产品标题和五行 Item Highlights，为 Amazon 商品整理可直接输入图片生成或编辑工具的完整资料与提示词。适用于各类商品，不把任何特定产品的外形、材质或场景规则泛化为通用事实。

## 输入与事实核对

先阅读全部文字与图片。建立三类信息：

- **产品事实**：仅来自用户明确提供的标题、五行、实拍图或用户后续确认，例如数量、尺寸、颜色、材质、包装内容、可宣传用途。
- **视觉参考**：参考图可用于布局、摄影风格、信息图形式、绳子折叠方式或场景氛围；除非用户明确确认，不能把其中的品牌、文字、尺寸、数量、材质、认证或产品结构当作本品事实。
- **待确认项**：无法可靠判定且会影响成品的内容，例如产品材质/表面、精确尺寸、包装数量、品牌型号、使用连接方式、可承重或安全声明。

在生成最终内容前，若存在待确认项，先用中文提出简短、明确的问题。不要猜测，不要用“高强度”“防水”“防锈”“耐高温”“可承重”“适合儿童”等未经用户提供或确认的声明。用户已明确要求不填写的字段（例如标题、类目）不再重复询问。

若资料完整，直接完成，不要为了形式化流程再提问。

## 固定输出框架

按以下顺序输出，使用清晰的中英文内容。用户只要求某个字段、某张图或一次局部修改时，只输出相关部分，不重复无关内容。

1. **填写内容 / Product Profile**
   - 品牌 / 型号（无品牌时写 `Unbranded / No Model`，仅在用户确认无品牌时使用）
   - 颜色
   - 材质 / 表面工艺
   - 目标人群
2. **卖点 / Selling Story**
   - 一行一个卖点；中文说明和可直接粘贴的英文版本。
3. **包装清单 / Package Contents**
   - 精确数量、单位和已知尺寸；公制与英制并列。只换算用户给出的数值，采用合理舍入。
4. **场景 / 构图 / Scene & Composition**
   - 主图布局：背景、产品数量、区域、摆放方向、特写、阴影、画面比例、文字限制。
   - 信息图：尺寸、材质细节、包装清单、使用方法等适合本产品的图位。
   - 场景图：符合实际用途的环境、视角、连接关系与主体重点。
   - 对每个图位给出可直接使用的中文提示词和英文提示词；若用户指定图生图或局部编辑，要明确“保留什么、只改什么、替换区域的具体内容”。
5. **禁用元素 / Guardrails**
   - 全局负面提示词，覆盖错误数量、错误尺寸、虚构配件、错误材质、非真实连接、变形、乱码、未授权品牌/认证/性能声明等。
6. **视觉色板 / Visual Palette**
   - 每次调用均提供 6 个针对当前产品、目标受众和参考图定制的色板，逐项写明颜色名称、Hex 和 RGB，并说明各色在图片中的用途。
   - 同时明确推荐的字体方向、光影方向、材质方向和信息密度；优先匹配参考图的节日、类目和零售视觉调性，不沿用其他产品的固定配色。
   - 用户仅请求单张图、局部修改或某个字段时，也须附上这一项；用户明确要求不需要时除外。

对用户上传的截图式表单，按表单字段逐项给出可复制的内容，并明确新增要求应填在“场景 / 构图”还是“禁用元素”。

## 图片提示词质量规则

- 主图遵守 Amazon 常见白底要求：纯白背景、商品完整可见、无无关道具；除非用户明确要求，主图不放文字、Logo、价格、促销标签或包装盒。
- 每个产品在全部图位中保持同一个真实模型：外形、孔位、纹理、部件数、颜色、比例和方向不能随图变化。实拍图优先于风格参考图定义产品结构。
- 当用户指出具体结构或安装逻辑时，将其写成明确的正向约束和负面约束；描述相对方向时，以被固定物、绳索或地面为参照，避免只写“左/右”造成歧义。
- 场景中的产品连接、接触、受力和安装应真实可信。不要展示Listing没有支持的高风险、承重或安全用途。
- 参考图中的文案只可作为版式灵感。需要展示文字时，使用用户确认的事实和清晰、简短的英文；避免生成可能拼错的小字。若编辑工具文字稳定性未知，可标注“预留后期排版文字区”。
- 用户提出修改时，先复述已理解的改动边界，保留用户说不改的部分；生成局部编辑提示词、正向提示词和负面提示词。

## 最终检查

在交付前逐项核对：

- 数量、单位、尺寸换算与用户资料一致。
- 材质和性能描述没有超出事实。
- 参考图中的产品、数字、品牌和结构没有误迁移。
- 每个画面中的产品外形与实拍/确认图一致。
- 主图、细节图、尺寸图、场景图和禁用元素均已覆盖用户需要的内容。
- 已提供与当前产品和参考图匹配的 6 色定制色板，以及字体、光影、材质和信息密度建议。
- 中文、英文对应内容语义一致；英文适合 Amazon North America，不使用夸大或无法验证的绝对化宣传。
